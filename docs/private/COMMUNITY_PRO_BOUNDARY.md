# Aiden Community and commercial capability boundary

## Aiden Community

The Community generation remains v4.20 with v4.20.x maintenance for critical bugs, security, compatibility, runtime correctness, and trust/safety maintenance.

Community includes:

- local runtime and durable Job/Attempt system;
- Workbench;
- Browser Operator;
- Apps foundation;
- External Coding foundation;
- Live Execution;
- provider and model setup;
- approvals;
- Evidence, Verification, and Proof;
- safe cancellation and recovery;
- artifacts.

The following are never commercial gates: truthful failure states, cancellation correctness, approval safety, protected paths, Evidence integrity, Verification integrity, Proof integrity, user-data export, and critical security updates.

## Planned commercial capabilities

- Reliable Automations;
- premium workflow packs;
- Agentic Presence;
- Learning Ledger;
- advanced Skill Intelligence;
- Remote Relay and multi-device operation;
- managed services;
- premium update channels;
- team/cloud collaboration;
- commercial support.

No v4.22 feature is implemented by this boundary pass. Future SDK or protocol components may be selectively opened only through a later explicit decision.

## Enforcement contract

Commercial behavior is capability-based through one edition authority. Unknown capabilities fail closed. Hosted services independently validate entitlements. UI hiding is never the enforcement boundary, and Community safety behavior remains enabled for every edition.
