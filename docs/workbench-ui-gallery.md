# Aiden Web — screenshot gallery

[Back to the README](../README.md#aiden-web-preview) · [Interactive screenshot tour](media/workbench-2026-09/tour.html)

Captured on **13 September 2026** from the local Workbench development build (runtime version 4.21.2), at **1440 × 1000** in dark mode. These are real browser screenshots, not design mockups. Local changes shown here are not evidence of a published release.

The capture uses a separate, unconfigured, read-only demo profile: no personal conversations, credentials, connected accounts, or real task results were imported. Setup-required, unavailable, and empty states are intentional. The workflow builder shows its built-in, unsaved starting template. Skills screenshots use the visible `browser` search filter.

Coverage: all **9 current main views**, **20 Settings sections**, onboarding, and **4 additional workflow/Apps views**. Screenshots show each page's captured viewport, not every scroll position or possible state. This is a UI tour, not an end-to-end execution or service-connection test.

To play the interactive tour after cloning/downloading the repository, open `docs/media/workbench-2026-09/tour.html` in a browser. GitHub displays HTML source rather than running the tour. No server, account, or network access is needed.
